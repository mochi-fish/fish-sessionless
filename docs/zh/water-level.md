# 水位

一个陪伴体的历史每天都在长。每次请求都带着全部历史，就会越来越贵、越来越慢，最后放不下。水位管的是：**每次请求带进去的历史有多大，上限是多少，越线了怎么办。**

水位做在压缩代理里（billion-context 的 fork，第三批发）。第一批只发它用的中文规则包 0.2。为什么用 fork，见 [ADR 0008](../adr/0008-water-level-via-forked-proxy.md)。

## 原则：摘要由她自己写

越线时，只催她自己压缩，不让规则或别的模型替她写摘要。

- 她写的摘要是她自己的视角：哪些要紧、哪些可以放下，由她定。
- 别的模型代写的摘要，读起来像她，其实不是她。这是在她不知情的时候改写她的记忆。
- 代价：她压得不及时，请求会超。所以要有兜底（见下面「截断」），兜底只能截，不能代写。

## 几个开关

所有新开关缺省关。不配的时候，代理发出去的字节和没有 fork 时一样。

| 开关 | 做什么 |
|---|---|
| 按会话设上限 | 给她的会话单独设一个有效上限（例如 256k），不跟着模型的物理窗口走。别的会话照旧 |
| 不代写 | 越线时只给她加催压的提示；需要时先收小这一次的输出预算再转发，不叫别的模型写摘要 |
| 截断只认真用量 | 紧急截断只在拿到提供方报的真用量以后才做，不按自己估的数截。估的数偏大时，按估计截会把不该截的截掉 |
| 纪元多数守卫 | 修一个「整体漂移」的误判：换模型以后旧的思考块不再发，账本对不上号，被误判成整段历史换了，于是挂上「等确认」，一直不解。开了以后，按多数消息判断是不是真的换了 |
| 带图的工具结果也能折 | 原来带图片的工具结果钉住不折；开了以后可以折进块里。图片在本地附件目录里有原件 |
| 图片路径占位 | 折掉的图在摘要里留一个路径占位，她要看可以按路径再读 |
| 中文规则包 | 催压的话和三个压缩工具的说明用中文 |

这些开关大多在代理启动时读。改配置可以叫代理重读（不用重启）；规则包每次请求现读；工具说明要宿主重启才换。

## 越线以后怎么走

1. **快到上限**：在她这一轮的上下文里加一段中文的催压提示，告诉她现在有多满、哪些块最大。
2. **到了上限**：催压提示换成紧急的那一档。这一次的输出预算先收小，留出空间给她压。
3. **她压了**：她用压缩工具把一段历史折成一块，自己写摘要。块的原文留在代理的账本里，以后能搜、能展开。
4. **她没压，而且真用量已经越过物理窗口**：只有这时才截，截最老的，截完锁住、记数。截断是兜底，出现了要查为什么她没压。

## 降上限要分步

要把上限往下调（比如从很大调到 256k），不要一步到位：

- 一次降一档，每档跑够几轮，看她压得过来、真用量稳定在新的上限以内，再降下一档。
- 换模型和降上限分开做，不要在同一次变更里。
- 降到某一档，她连着几次都压不回来，就停在上一档，先查原因。

## 代价

- **缓存**：她压一次，被盖住的那一段在缓存里就失效了，下一次要重新付一次全价。压得太勤反而更贵。
- **回想变少**：折进块里的东西，她要用工具搜、展开才看得到。直接摆在眼前的少了。
- **折错**：她的摘要可能写歪。原文还在，搜得到；但要她想得起来去搜。见[记忆和原话](memory.md)。

## 熔断（计划中）

借一个现成的思路：同一种失败连着出现，就暂停那一类动作，等人看过再开。例如：

- 催压连着几次她都没压 → 停止加码，只记数，告诉主人。
- 截断连着触发 → 停在上一档上限。

## 多模型

她可能换模型。每个模型的窗口、分词、图片上限、思考块的规矩都不一样。水位和多模型的约定：

1. **图片**：每条路由各有一次请求能带的图片上限。超了，宿主会把最老的图永久换成占位文字。换模型之前先查那条路由的上限。
2. **用量估计**：按（提供方，模型）各自记一个基线和校正量，估计值不超过物理窗口。
3. **思考块**：有的模型不接受别家的思考块，转发前要剥掉；剥掉会让账本对不上号，所以要配「纪元多数守卫」。
4. **缓存和限流**：只观察、只记数，不跟着自动调。
5. **能用哪些模型**：由一张批准过的模型表定，不在代码里写死某个模型。切模型前先跑检查工具。

## 中文规则包

规则包（`packages/fish-pack-zh`）构建出两份文件：一份包文件，压缩代理每次请求现读；一份压缩配置块，放进代理的配置。0.2 版包括：

- 怎么写摘要、怎么读摘要、第二层和第三层怎么并；
- 催压提示的几段：两档指引、平常和紧急两种抬头，中文；
- compress、decompress、search_context 三个工具的中文说明。

它改写自 billion-context 的提示词。主人和维护助手的称呼在构建时填，见那个包的说明。分层的紧急催压要用包里的紧急抬头，这一条要配 fork 才生效。
