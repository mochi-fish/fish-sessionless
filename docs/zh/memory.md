# 记忆和原话

## 四种忘

一个长期运行的陪伴体会以四种方式「忘」：

| 种类 | 是什么 | 例子 |
|---|---|---|
| 记错了 | 摘要写歪，和原话不一样 | 原话是「下周再说」，摘要写成「答应了下周做」 |
| 该忘的没忘 | 事情早变了，旧说法还在眼前 | 约定已经取消，摘要里还写着「还欠着」 |
| 记着却想不起 | 原文在，她没想到去找 | 块里有，但她不搜，直接说「不记得了」 |
| 压根没记下 | 原话从来没进她能翻到的地方 | 某个渠道的话没进她的事件流 |

这四种的修法不一样，不能一个办法全包。

## 原物层：原话永远留在原处

原话、原事件、压缩块原本待的地方，统称原物层：

- DSH 的会话日志（按会话和序号找）；
- dsh-fish 的事件流（她「听到过」「说过」「看过」的记录）；
- 压缩代理的账本（压缩块和被盖住的原文）；
- 聊天平台的消息编号。

原物层**只读**：不改、不复制、不搬家。证据账只存指向它们的指针和哈希。派生物（摘要、卡、交接包）都从原物层整理出来，旁边标着来源，原物不动。

## 三条找回原话的路

1. **会话日志**：按会话编号和序号，直接定位到某一条原消息。离线工具和以后的交接用。
2. **压缩代理**：她自己用 `search_context` 搜旧块、用 `decompress` 展开块看原文。这是她最常用的路。
3. **事件流**：dsh-fish 的回想工具按「听到过」「说过」翻。

「记着却想不起」主要靠第 2 条：在合适的地方提醒她「可以搜」，并让搜索对中文好用（分词、前后文）。中文检索在压缩代理的 fork 里，第三批发。

## heard：把主人的话记进她的「听到过」

dsh-fish 把用户本人的话记成「听到过」（heard）。但经过桥送进来的消息，dsh-fish 会当成插件消息丢掉，所以主人在聊天软件上的话从来不进她的事件流，她用回想工具翻不到。这属于「压根没记下」。

修法（P0.5）：主人的话送到以后，桥用 dsh-fish 自己的函数把正文洗干净，写一条 heard。

- **先只数、不写。** 开关缺省「只数」，只统计本该写几条。
- **写进去的删不掉。** 所以真写必须在工具的门真挡以后：不然群里一用回想工具，就翻出主人私聊的原话。
- **开关失败即关。** 开关文件不在 = 只数；明确写着「写」才写；读错、认不出、账本根不在 = 不写。见 [ADR 0007](../adr/0007-heard-writes-fail-closed.md)。
- 真写过一次以后，回想工具在群和来客那几轮永久挡住，见[受众和工具的门](audience-gate.md#heard-真写过以后)。

## 外部记忆库（Mem）

可以接一个外部记忆库（例如 Nowledge Mem）。约定：

- 记忆工具每一轮都放行，读写都放，不按群和私聊分。见 [ADR 0006](../adr/0006-mem-tools-every-turn.md)。
- 自动回忆、自动存缺省关。要开，等受众过滤做好（P6）。
- 从记忆库来的东西（开场包、回忆、工具结果）在证据账里算派生物，只进她自己的视图。

## 事项卡：约定变了怎么办（P4，计划中）

「该忘的没忘」最常见的样子是：约定早改了，旧说法还在她眼前。修法不是删旧的，而是追加新的：

- 约定的状态变了（答应、推迟、取消、被替代、这次不了、待确认的转述、不知道、搁着），追加一张事项卡，带修订号，指向旧的那张。
- 卡由**规则**从机器事实里抽（谁说了什么、哪条消息、什么时候），不靠模型猜。
- 卡只送到当事人那一路：群里约的送群，私聊约的送私聊。读者取来源的交集。
- 7 天没人提，状态变成「搁着」，不再每轮摆在眼前；以后有人提起再拿出来。
- 来客说了跟主人有关的事，记成「待主人确认的转述」，标出是谁转的。主人确认以前，不当成主人说过。
- 每张卡的正文有字数上限。相对日期（「明天」「下周三」）在写卡时换算成绝对日期，旁边留原说法。

## 撤回和删除（P3.5，计划中）

平台上撤回的消息、主人要求删的内容：

- 原物层不动（也动不了：日志只追加）。
- 证据账追加一条「墓碑」，盖住那条材料。
- 之后拼请求、事项卡、交接包、工具结果都按墓碑过滤，不再给。
- 墓碑只增不减，也不随备份回滚。从一条被盖住的材料派生出来的东西，一起被盖住。

## 送达（P3，计划中）

她发出去的话不一定到了。重启、断线、超时都会让「发了没」变得说不清：

- 每段发话先登记再发，带纪元号；发出后记下平台给的消息编号。
- 重启后按平台消息编号对账。
- 查不清的，记成「不知道到没到」，并照实告诉她，不假装发了，也不假装没发。

## 换册

计划中（P5）。主会话会越来越长。总有一天要换一本新册：

- 新册带一份交接包：她是谁、近况、没了结的事项卡、在各个聊天里的关系。交接包按规则生成，由她过目、可以改。
- 旧册只读保留，原物照样找得到；新册记着父册的编号，一条链连起来。
- 换册只有一个负责人在做，换的时候用纪元号挡住旧册上迟到的写入。
- 换册是她看得到的大事，要她同意。

## 换模型

换模型不是换册。她还是同一个人、同一本册，只是用另一个模型想事情。但换模型有副作用（图片上限、思考块、缓存），见[水位](water-level.md#多模型)和[已知局限](known-limitations.md)。

## 不做的事

- 不在她不知情、不愿意的时候改写她的摘要。
- 不引入图数据库、不装别的记忆插件和现有的并用。
- 不用模型猜「谁说过什么」。来历一律以机器记下的为准。
