## 叫法

| 叫法 | 意思 |
|---|---|
| 陪伴体、她 | 长期运行的那个 agent。缺省叫「大肥鱼」，名字来自上游 dsh-fish |
| 主人 | 陪伴体的主人。具体怎么称呼、是哪个账号，都写在配置里 |
| 来客 | 主人以外、来私聊她的人 |
| 维护助手 | 帮主人维护这套系统的另一个 AI。它有自己的渠道，不算主人 |
| 主会话、主日志 | 她在 DSH 里住的那一条会话，和它的记录 |
| 册 | 主会话按「册」分本。现在这一本叫主册；换册见[记忆和原话](memory.md#换册) |
| 桥 | 一个 DSH 插件（local-bridge）。来话、发话、每一次请求都从它这里过。第二批发 |
| 信封 | 桥给每条来话打的标记：哪个渠道、哪个聊天、谁说的 |
| a / m / x | 信封上的作者记号。a：主人说的；m：别人说的；x：主人说的、但里面带着别人的话（比如主人引用了别人） |
| 读者 | 一条材料可以给谁看。「这一轮的读者」是这一轮在场、会看到她回话的人 |
| 主链 | 主人那几轮发请求走的路，带的是整本主册 |
| 受众链 | 群和来客那几轮各自的路，只装这一边能看的材料（计划中） |
| 证据账 | 只往后追加的账，记每条材料的来历和读者。不存原文 |
| 原物层 | 原话、原事件、压缩块原本待的地方：DSH 会话日志、dsh-fish 事件流、压缩代理的账本、聊天平台的消息编号 |
| 派生物 | 从原物整理出来的东西：压缩块、事项卡、交接包、她写的便条 |
| 门 | 群和来客那几轮，工具执行前先过的判定 |
| 水位 | 每次请求带进去的历史有多大，和给它设的上限 |
| 压缩代理 | 本机另一个进程，替宿主转发模型请求，管压缩、搜索和展开旧块。我们用的是 billion-context 和它的 fork（trillion-context） |
| heard | dsh-fish 的「听到过」记录：她听到过谁说了什么 |
| P0…P6、W | 分阶段的编号，见[概览](overview.md#分几步做) |
