# 部署前提

**先说清楚**：这是自用为主的项目，下面写的是我们自己跑过的组合。别的版本没验过，不保证能用。第一批单独装，拼不成一套能聊天的系统（见最后一节）。

## 宿主：DSH

| 项 | 要求 |
|---|---|
| DSH 版本 | 0.2.2-rc.3 到 0.2.2-rc.5 跑过。更早、更新的都没验过 |
| 用到的插件口子 | 会话事件（落盘以后通知）、工具执行前、工具执行后、工具执行、工具结果、系统提示拼装、模型请求流 |
| 加载方式 | 本地插件按路径加载：放进 profile 的本地插件目录，在 profile 的 `cordis.patch.yml` 里插一行 |
| Node | 插件跑在宿主自带的运行时里。离线测试用 Node 22 起 |

宿主升级时要注意的几件事：

- **兼容检查会悄悄跳过插件。** DSH 会看插件声明的宿主版本范围；当前版本不在范围里，整个插件包被跳过，桌面版不报错。升了宿主以后，看一眼插件提供的工具还在不在。需要的话，在宿主停着时用新版自带的命令行给那一对精确版本开豁免。
- **宿主的接口会变。** 每次升宿主前，对照新旧两个版本标签的源码，看插件用到的接口有没有改。DSH 是开源的，按标签比代码，不要从安装包里读。
- **模型请求流口子是文档里说「只读」的。** 桥在那里改写请求（第二批），靠的是宿主现在的实现。宿主改了这一点，桥的请求改写就失效。见[已知局限](known-limitations.md)。

## 陪伴体：dsh-fish

| 项 | 要求 |
|---|---|
| 版本 | 1.0.x（1.0.2 上验过） |
| 用到的东西 | 它的事件流格式、「听到过」的写入函数、配置读取、回想工具的输出格式 |

dsh-fish 每次升级，都要拿新版重跑一遍桥和 heard 的测试：heard 靠 dsh-fish 内部函数的参数顺序和返回形状，只有拿真的包才核得到。

## 聊天：OneBot

| 项 | 要求 |
|---|---|
| QQ 接入插件 | dsh-onebot-qq 0.10 到 0.11 跑过 |
| OneBot 实现 | 任何有正向 WebSocket 的 OneBot v11 实现。我们只在一种实现上跑过 |
| 录制器 | 以第二个客户端连 OneBot 实现的正向 WebSocket，和宿主那条连接互不影响。要求实现把事件推给每个连着的客户端 |

## 压缩代理

| 项 | 要求 |
|---|---|
| 版本 | billion-context 0.1.213 起；水位、出口哈希、中文检索要 fork（trillion-context，第三批发） |
| 中文规则包 0.2 | 在上游版本上就能用（催压和工具说明的中文）；分层的紧急抬头要 fork |

注意：

- 代理是本机另一个进程，进程名是 node。按名字停宿主停不到它；宿主快速重启时，新宿主可能接着用旧的代理进程。换代理的包、或者要它重新加载时，停宿主以后要等旧代理进程真的退了，光看端口没人听不够。
- 代理的自动更新建议关掉，升级前先核过。

## 外部记忆库（可选）

Nowledge Mem 这类外部记忆库可以接。自动回忆、自动存建议关着（见[记忆和原话](memory.md#外部记忆库mem)）。

## 第一批能单独用什么

| 东西 | 单独能用吗 |
|---|---|
| `packages/ledger-core`、`packages/audience` | 能。纯 JS，只用 Node 自带模块，可以拿去做别的项目 |
| `packages/config` | 能。只读一份 JSON |
| `packages/fish-ledger` | 能装，能记账（落盘以后的事件、工具结果、用量）。工具的门也能判，但群和来客的认人要靠桥打的信封，没有桥时，所有轮都认不出来，按最严算 |
| `packages/fish-pack-zh` | 能。放进压缩代理的规则包目录 |
| `tools/` | 能。隐私扫描、离线守卫、测试排队这些和宿主无关 |
| `evals/` | 能。只用合成的世界 |
| `recorder/` | 能。接任何 OneBot v11 实现。有的实现拿不到嵌套转发的内层，要整包展开得自己写外挂模块（见 `recorder/README.md`；本仓库不带解包实现和任何协议定义文件） |
| 认人、送消息、请求改写、发话 | 不能。这些在桥里，第二批发 |

## 装之前

- 先在副本上跑：把 profile 整份拷到别处，用 `DSH_HOME` 指过去起一个副本宿主。证据账在副本上不会写进真账（见[证据账](evidence-ledger.md#副本写不进真账)）。
- 测试一律指向临时目录：`FISH_LEDGER_DIR` 设成测试自己建的目录。
- 不要把上线位置的插件文件本身交给测试跑：有的测试会删改插件旁边的状态文件。
