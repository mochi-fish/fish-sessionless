# 0001. 她只住一条会话

状态：采用

## 背景

陪伴体同时面对主人、几个群、来客，还有她自己醒来的那几轮。最直接的隔离办法是每个房间一个会话：群里的会话看不到私聊，天然干净。

但那样她就成了好几个人。群里的她不知道私聊里刚发生的事，私聊里的她不记得群里说过的话。陪伴的价值在于「同一个人一直在」，拆开就没了。

## 决定

- 她只有一条主会话、一份主日志。不管从哪个渠道来、对谁说，回复都落回这一份。
- 隔离不靠拆会话，靠旁边加的东西：证据账记每条材料的读者；工具的门挡群和来客那几轮的回想；以后按受众从空开始拼请求（受众链），只装这一边能看的材料。
- 受众链只是「发请求走的路」，不是另一个她。受众链上的回复照样落回主日志。
- 生活史太长时换册（新的一本带交接包，旧的只读），不按房间拆。

## 后果

- 她保持一个人：记得各处发生的事，说话前后一致。
- 隔离要靠额外的机制，而且在 P2 之前有缺口：群那一轮的第一次请求仍带着整本主册（见已知局限）。
- 主日志会一直长，需要水位和换册。
- 所有新机制都必须是「旁加」：不往她的会话里写删不掉的元数据。
