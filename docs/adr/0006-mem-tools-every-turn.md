# 0006. 外部记忆库的工具每一轮都放

状态：采用

## 背景

陪伴体可以接一个外部记忆库（例如 Nowledge Mem），有一组读写工具。按工具的门的原则，能翻到过去的工具在群和来客那几轮应该挡。

但记忆库是她自己整理、自己存的东西，是她「长在身上」的记忆；在群里也要用。按群和私聊分库、分权限，要先有受众过滤（P2、P6），现在做不到。

## 决定

- 记忆库的工具每一轮都放行，读写都放，不按群和私聊分。这是主人定的取舍。
- 自动回忆（每次请求前自动查）和自动存（每轮结束自动写）缺省关。要开，等受众过滤做好（P6）。
- 从记忆库来的东西在证据账里算派生物，只进她自己的视图；拼受众链时不带。

## 后果

- 她在群里也能用自己的记忆。
- 她存进记忆库的私聊内容，群里那一轮也查得到。这是已知、接受的口子，写在已知局限里。
- 不想要这个取舍的部署，可以在门的开关里把记忆工具加进挡的单子。
- 以后做 P6 时要重新看这条。
