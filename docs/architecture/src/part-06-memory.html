记忆和原话

折掉的不等于丢掉：原话一直在，账上记着去哪找

她眼前的那份请求每一轮现拼；往下是她和规则整理出来的派生物；再往下是只存指针的证据账；最底下是原物层，永远不改、不复制。要原话，顺着指针回原处取。

她为什么会忘，这套方案各管哪一种

① 记错了
摘要写歪，和原话不一样。管法：原文留在压缩代理的账本里，搜得到、展得开；事项卡用追加的新卡取代旧说法。
② 该忘的没忘
约定早改了，旧说法还在眼前。管法：事项卡（P4）：状态变了追加一张，7 天没人提就「搁着」；撤回的用墓碑盖住（P3.5）。
③ 记着却想不起
原文在，她没想到去找。管法：提醒她可以搜；中文检索的分词和前后文；相对日期旁边注上绝对日期。
④ 压根没记下
主人在聊天软件上的话，经桥送进来，被当成插件消息丢掉，从来不进她的事件流。管法：heard（P0.5）：桥用 dsh-fish 自己的函数洗干净再写；先只数，门真挡以后才真写；开关失败即关。
